## 🎨 Visual Concept & Inspo Architecture
Directly inspired by early-2000s **Barbie Diaries**, **MyScene.com web portals**, and the **All About Barbie Dreamhouse Infographic**, this portfolio abandons generic emoji clutter in favor of clean, disciplined graphic design, distinct page layouts, and authentic Y2K multimedia artifacts.

### 🏛️ Distinct Page Layouts
1. **00 // All About Me (Hero & Polaroid Spread)**
   - *Inspo: `myscene.com` & Barbie Diaries*
   - Clean top portal navigation bar with official Barbie script branding.
   - Pinned **Polaroid photo card** of Angela with a realistic silver paperclip and official barcode label.
   - Ruled **Pink Notebook Diary Sheet** with structured identity fields and clean editorial metrics.
2. **01 // The Story (Autobiography & Live Dispatch)**
   - *Inspo: `myscene.com` Phone Widget & Blog Sheet*
   - Clean chapter blocks for Angela's core philosophy, Cebu roots, game development passions, and growth mindset.
   - Interactive **Y2K Pink Mobile Phone Widget** with SMS dispatch, battery/signal bars, and keypad.
   - Interactive **Milestone Year Slider (2023 - 2026)**.
3. **02 // The Skill Sheet (Dreamhouse Infographic)**
   - *Inspo: All About Barbie Dreamhouse Infographic*
   - Framed within a clean mint teal (`#68C7B5`) dollhouse blueprint with distinct room cutaways.
   - **Lipstick Bar Chart:** Rounded-top horizontal Altair bar chart in berry and rose shades.
   - Clean data table, competency descriptions, and categorized tech wardrobe badges.
4. **03 // The Project Closet (Runway & Code Releases)**
   - *Inspo: Character Tab Ribbon & Catalog Spread*
   - Interactive project ribbon selector: **[01] BantAI Buddy**, **[02] Salamin at Bakal**, **[03] Crossroads of Us**, and **[04] CampusTails**.
   - Spotlight dossier with competition badges, architecture breakdown, and verified GitHub links.
5. **04 // Dear AJ (Airmail Stationery & Reader Mail)**
   - *Inspo: 2000s Teen Magazine Write-in Columns*
   - Clean airmail stationery sheet with postage stamp, postmark header, and validated input fields.
   - Real persistent JSON storage, delivery receipts, and downloadable portfolio resume (.md).
6. **05 // The Y2K Lounge (Developer Archetype Quiz & Archive)**
   - Interactive 3-question developer archetype quiz (Visionary Lead, Game Architect, Competition Specialist, Interface Stylist).
   - Authentic moodboard gallery and retro Winamp-style coding mixtape player.

## 🚀 Quickstart & Installation

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the application
streamlit run app.py
```
Open `http://localhost:8501` in your browser.
